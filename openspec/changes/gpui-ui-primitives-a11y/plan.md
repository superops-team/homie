# GPUI UI Primitives A11y First Slice Plan

## Scope

Create the first semantic UI primitive in `homie-ui` and migrate the settings
close control as a low-risk real usage.

## In Scope

- `Button`, `ButtonVariant`, `ButtonSize` in `homie-ui`.
- Disabled-state behavior and tests.
- Settings dialog `close-settings` migration.

## Out Of Scope

- Migrating every button-like control.
- Full AccessKit integration without a pinned local pattern.
- Visual redesign.
